# Atbash Cipher Implementation

A simple Python project that demonstrates the implementation of the Atbash cipher. This project was developed to practice string manipulation and algorithmic logic in Python.

## Features
- Encrypts and decrypts text using the Atbash cipher algorithm.
- Handles both uppercase and lowercase letters while preserving spaces.
- Lightweight and easy to run.

## How to Run
1. Ensure you have Python installed.
2. Clone this repository to your local machine.
3. Run the script using the following command:
```bash
python main.py
```markdown
